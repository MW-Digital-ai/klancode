# Política de Segurança — KLANCODE (MW Digital)

Este repositório é público apenas para apresentação institucional.

## Reporte de Vulnerabilidades

Caso identifique qualquer problema de segurança ou exposição indevida em propriedades da KLANCODE:

1. **Não abra Issue pública** com detalhes exploráveis.
2. Utilize a aba **Security > Advisories** ("Report a vulnerability") deste repositório ou de qualquer repositório aplicável da organização [`MW-Digital-ai`](https://github.com/MW-Digital-ai).
